# [PM 인사이트 리포트] 서울시 CCTV 및 인구 데이터 분석 프로젝트의 서비스 재정의

## 1. 프로젝트 개요 및 기존 레거시 교육의 문제점 (As-Is)

### 1.1 기존 방식의 한계

- 2010년대식 엑셀 파일 로컬 다운로드, 복잡한 파이썬 로우 레벨 문법(`Series`, `DataFrame`, 구식 `ix` 인덱서 등) 암기 중심.
- 텍스트 출력과 콘솔 창, 그리고 OS 폰트 설정이 깨지네 마네 하는 비효율적인 시각화 방식에 매몰됨.
- 현업 경력자들과의 경쟁에서 전혀 쓸모없는 단순 코드 타이핑 노가다에 치중됨.

### 1.2 치명적인 기획적 허점

- 오직 주민등록상 인구수(주거 인구)만을 기준으로 삼아, 낮 시간에 사람이 폭증하는 오피스·상업 지구(예: 강남, 중구 등)의 진짜 치안 및 CCTV 수요(생활 인구)를 전혀 반영하지 못하는 탁상공론식 통계임.

---

## 2. PM 관점의 서비스 재설계 및 아키텍처 혁신 (To-Be)

### 2.1 핵심 가치 제안 (Value Proposition)

- 분석용 데이터는 백엔드(Python + SQL)에서 가공하되, 최종 결과물은 유저가 브라우저에서 직관적으로 확인하고 필터링할 수 있는 **인터랙티브 웹 대시보드**로 제공해야 함.

### 2.2 모던 테크 스택 (Modern Tech Stack)

| 구분 | 내용 |
|---|---|
| **Data & Backend** | Python, SQL을 활용한 데이터 정제 및 API 서버 구축 (향후 React 전환을 고려한 표준 JSON 규격 준수) |
| **Frontend & UX** | HTML/CSS/JS 기반의 모던 카드 UI 및 인터랙티브 그래프(Chart.js, D3.js 등)를 활용하여 폰트 깨짐 없는 깔끔한 웹 환경 구축 |

### 2.3 바이브 코딩(AI 협업)을 통한 실행력 극대화

- 문법을 일일이 손으로 치는 소모적인 방식에서 벗어나, AI 에이전트와의 협업을 통해 서비스의 뼈대와 UI/UX를 빠르게 프로토타이핑하고 실무형 결과물을 도출함.

## PM 관점

### 🐍 Python — 데이터 처리 및 백엔드

> **파이썬은 백엔드에서 대용량 데이터를 수집하고, 정제하고, DB에 안전하게 저장·관리하는 파이프라인(ETL) 및 데이터 처리 영역에 사용한다.**

- **데이터 수집**
  - 외부 API 및 다양한 데이터 소스에서 데이터 수집
  - 서비스 운영에 필요한 데이터 자동 수집

- **데이터 정제 및 가공**
  - 불필요하거나 잘못된 데이터 제거
  - 데이터 형식 통일 및 전처리
  - AI/머신러닝 학습에 필요한 데이터셋 구축

- **DB / SQL 연동**
  - 수집한 데이터를 데이터베이스에 저장
  - SQL을 활용하여 데이터 조회·수정·관리
  - 모델 학습용 데이터셋 관리

- **백엔드 API**
  - Python + FastAPI 등을 활용하여 경량화된 예측 API 구축
  - 프론트엔드에서 요청한 데이터를 처리하고 결과 반환

---

### 🎨 HTML / CSS / JavaScript — 프론트엔드

> **유저가 실제로 눈으로 보고 조작하는 화면과 시각화는 HTML/CSS/JS를 활용하는 프론트엔드 영역이다.**

- **HTML**
  - 웹 페이지의 구조와 콘텐츠 구성

- **CSS**
  - 화면 디자인 및 레이아웃 구성
  - 반응형 UI 구현

- **JavaScript**
  - 사용자 인터랙션 처리
  - API 데이터 호출 및 화면 반영
  - 차트 및 데이터 시각화
  - 실시간 UI 업데이트

예시:

- 쇼핑몰 UI
- 관리자 대시보드
- 데이터 분석 화면
- 차트 및 통계 화면

---

## 3. 결론 및 시사점
